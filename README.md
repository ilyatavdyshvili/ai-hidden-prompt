# ИИ-сервис обнаружения скрытых промптов в изображениях

Дипломный проект: обнаружение скрытых текстовых инструкций (prompt injection / hidden prompts), которые становятся читаемыми или интерпретируемыми после масштабирования, увеличения разрешения или иных преобразований изображения.

## Цель

Разработать сервис, который принимает изображение, выполняет многошаговый анализ его содержимого и возвращает:
- наличие/отсутствие подозрительного скрытого текста;
- найденные области изображения;
- распознанный текст;
- оценку уверенности;
- классификацию типа инструкции;
- объяснимые признаки, на основании которых принято решение.

## Структура

- `docs/technical-specification.md` - основное техническое задание.
- `docs/architecture/` - архитектура и описание пайплайна.
- `docs/data/` - требования к обучающим и тестовым данным.
- `docs/testing/` - стратегия валидации и тестирования.
- `api/openapi.yaml` - контракт REST API.
- `README.md` - краткое описание проекта.

## Предлагаемый стек

Python 3.11+, FastAPI, PyTorch, OpenCV, Pillow, NumPy, Tesseract/EasyOCR/PaddleOCR или современная OCR-модель, Hugging Face Transformers, Docker, PostgreSQL/MinIO - при необходимости хранения результатов и исходных файлов.

## Важное ограничение

Система предназначена для обнаружения потенциально скрытых инструкций и поддержки анализа безопасности. Она не должна автоматически выполнять найденный текст как инструкцию.
